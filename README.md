# MEMECOIN SNIPER

A single-page Solana memecoin sniper. It watches DexScreener for tokens with
whale-sized average buys, routes entries and exits through Jupiter, and signs
everything locally in your browser.

**[Setup instructions → SETUP.md](SETUP.md)**

Quick start:

```bash
git clone https://github.com/bill3821/Hshsbd.git
cd Hshsbd
./launcher/install-desktop-icon.sh     # Windows: launcher\install-desktop-icon.bat
```

Then double-click the **Fly Trader** icon on your Desktop.

---

This bot trades real SOL automatically. Use a dedicated wallet holding only what
you can afford to lose. Your private key is never transmitted — it stays in the
page and signs transactions locally — but anything you paste into a browser tab
is only as safe as the machine you paste it on.
